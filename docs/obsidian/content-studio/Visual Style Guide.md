# Visual Style Guide

Use one clear focal idea, deep blue, warm parchment, restrained gold, generous negative space, and high-contrast typography. Prefer real documentary ministry photography when available. Use one headline, one supporting line, and one action/detail group.

Avoid glossy AI-surreal art, fake crowds, plastic skin, excessive glow, random gradients, floating icons, and decorative clutter. Protect faces, logos, dates, and calls to action from crops and interface overlays. Include accessibility text and verify legibility at the destination size.
