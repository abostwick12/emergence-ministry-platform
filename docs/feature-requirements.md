# Feature Requirements

## Product Vision

EMERGEnce Ministry Platform should feel like a ministry command center, not a generic spreadsheet. Google Sheets should serve as the data layer, while the Apps Script web app provides the primary user experience.

## Core Modules

- Events
- Kanban
- Documents
- Budget
- Leader List
- Student List
- Worship
- Communication
- Voice Profiles
- Prompt Templates
- System Settings
- Archive

## First Workflows

- Event Planning Assistant
- Baseline Checklist Builder
- Parent Email Generator
- Leader GroupMe Generator
- Text Message Generator
- Push Notification Builder
- Volunteer Requirement Tracker
- Event File Organizer
- Communication Review Assistant

## Safety

- Draft communications only until explicitly approved.
- Do not expose student-sensitive notes unnecessarily.
- Do not store secrets in code.
- Log important actions.
